# Task 📋

Проект для управления задачами и отслеживания прогресса.

## ✨ Особенности

- 📝 Создание и управление задачами
- ✅ Отслеживание статуса выполнения
- 🏷️ Система тегов и категоризации
- 📊 Статистика и аналитика

## 🚀 Быстрый старт

### Требования
- Node.js 16+
- npm или yarn

### Установка

```bash
git clone https://github.com/paprikamaprika/task.git
cd task
npm install
```

### Использование

```bash
npm start
```
